# Country boards — a jobslop plugin

Local job boards: Reed (UK), Adzuna (19 countries), Jobs2Careers and USAJOBS (US), Jobindex (Denmark) and Jobbird (Netherlands).

## What it adds

- **Job boards:** Reed (Big UK job board (needs a free key)), Adzuna (Job search in many countries (needs a free key)), Jobs2Careers (Large US job search), USAJOBS (US government jobs), Jobindex (Denmark's biggest job board), Jobbird (Dutch job board)
- **Settings:** Reed API key, Adzuna App ID, Adzuna App Key, USAJOBS API key, Email you registered with
- **Its own words in:** da, es, nl

## Install

It comes with jobslop and is switched on already (**Settings → Plugins**).

To get a newer version before jobslop's next release: **Settings → Plugins → Check for plugin updates**,
or paste `https://github.com/JobSlop/jobslop-plugin-country-boards` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
